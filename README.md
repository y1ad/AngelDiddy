# AngelDiddy

APK simple que:
1. Al abrirla, pone la imagen como fondo de pantalla
2. Muestra un Toast de confirmación
3. Se cierra automáticamente

Nombre de la app: **AngelDiddy**

## Cómo compilar con GitHub Actions

1. Crea un repositorio nuevo en GitHub
2. Sube **todos** los archivos de este proyecto
3. Ve a la pestaña **Actions**
4. Ejecuta el workflow **Build APK**
5. Descarga el artefacto **AngelDiddy-APK**

## Notas
- La imagen está en `app/src/main/res/drawable/wallpaper.jpg`
